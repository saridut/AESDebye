Welcome to AES-DEBYE's documentation!
=====================================

AES-DEBYE is a high-performance software package designed for calculating Debye scattering patterns from atomic configurations. It is optimized for accuracy, speed, and scalability, making it suitable for large-scale simulations in materials science, chemistry, and physics.
